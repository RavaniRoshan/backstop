**What not to say, and why.** The reconciliation has never been run against a
real provider statement; the column names are transcribed from published
reporting surfaces. The bundled rate card prices Anthropic's 5-minute
cache-write tier, so a 1-hour TTL is under-counted by 37.5% of that component.
The npm package is a partial port with a different interception strategy. Say
none of these in a launch post — say them in the docs, where they already are,
and let the curious reader find them. A launch post that omits them is not
dishonest; a launch post that asserts the opposite is.

## Announcement — long form (blog, changelog, README-adjacent)

> **Backstop 0.7.0: it can now tell you what the money was for.**
>
> Backstop is an in-process guardrail for the OpenAI and Anthropic SDKs. You
> wrap the client once; it enforces token budgets, priority admission,
> concurrency ceilings, circuit breaking and retry policy around every provider
> call. That has been the shape of it from the start.
>
> What is new is the other half of the problem. Once you are stopping runaway
> spend, the next question is the one finance asks: which team spent it, and is
> that number right?
>
> 0.7.0 answers both. Turn on the ledger and every completed request produces
> one immutable, priced, attributed row — model, token counts, latency, your own
> attribution dimensions — written to a file you own. Group it by team and export
> the charge-back.
>
> And because a charge-back you cannot check is just a number someone made up,
> `backstop reconcile` compares the ledger against a provider statement and
> reports the variance per model. A model the price card does not carry is shown
> as unpriced, not quietly defaulted. A model the provider billed and your ledger
> never recorded is its own row, not netted away.
>
> The ledger is opt-in and off by default. Wrapping a client still costs one
> function call and nothing else.
>
> Also in this release, and worth knowing about: `backstop serve` returned HTTP
> 500 on every request in its default configuration. It works now. Nineteen other
> correctness fixes went in, four of which could have lost money.
>
> ```bash
> pip install backstop-ai
> ```
>
> MIT licensed. 1342 tests, as of `v0.7.0`. The walkthrough at the top of the site is 132 seconds
> and every frame in it is the product running.

## Before you post

- [ ] `npm publish` has happened, or the post should not mention npm. It is
      still 0.6.0 against PyPI's 0.7.0, and npm requires 2FA that only you can
      satisfy. See `.github/workflows/ci.yml` → `npm-publish`.
- [ ] You have run `backstop reconcile` against one real provider statement.
      Until then, do not claim the reconciliation is calibrated.
